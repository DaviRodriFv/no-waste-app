# No Waste App

Estrutura inicial de um app Next.js para integrar com backend.

## Pastas criadas

- `app/` - app router, páginas e estilos globais
- `components/` - componentes reutilizáveis
- `hooks/` - hooks personalizados
- `services/` - chamadas de API e integração backend
- `public/` - recursos estáticos

## Como usar

1. Instale dependências com `npm install` ou `yarn install`.
2. Rode em modo de desenvolvimento com `npm run dev`.

> Se o comando `npm` não estiver disponível, instale o Node.js e o npm antes de prosseguir.
